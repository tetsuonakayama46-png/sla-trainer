# SLA Trainer（スマホ版・単体PWA）— 英語初心者向け 3か月カリキュラム

https://tetsuonakayama46-png.github.io/sla-trainer/

## 使い方
- Safari / Chrome で開く → 「有効にする」→ マイク許可（初回のみ）→ ホーム画面に追加
- 1日1セット約5分。新しい文4つ（各2回）＋復習4つ。イヤホン推奨（電車内は環境音で閾値を自動調整）

## 3か月の構成（12週・165文・`curriculum.js`）
| フェーズ | 週 | 内容 | ゴール |
| --- | --- | --- | --- |
| 0 音の土台 | 1–2 | あいさつ・返事・数・2〜3語 | ゆっくりの音で口が勝手に動く |
| 1 生活の定型文 | 3–5 | 自己紹介・頼む/聞き返す・電話/メール/約束 | 3〜6語の決まり文句を普通の速さで |
| 2 英借文（置き換え） | 6–9 | Can I have / Could you / I need to / I'd like to / Do you have / How long / Is it okay / I'm going to / Let me / I'm not sure if | 型10個×中身の入れ替え |
| 3 状況で即答 | 10–12 | 現場の指示と報告・gonna/wanna/gotta・交渉と仕上げ | 状況を見て3秒以内に口から出す |

## 1文ごとの5ステップ（合格2連続で上がる・不合格2連続で1つ戻る）
1. 意味＋ゆっくり（日本語の意味を見ながら 0.6倍速を真似る）
2. いっしょに（0.8倍速に重ねて言う）
3. ひとりで（通常速度・文字を見て言う）
4. 見ないで（英文を隠し、音だけ聞いて言う → 結果で英文表示）
5. 状況で即答（日本語の状況だけ見て3秒以内に言う → その後お手本）

## 週の進み方
- 日数で週が進むが、前の週の文の70%が「ひとりで」以上になるまで次の週へ進まない（復習週になる）
- 到達済みの文も3日以上空くと復習に戻る（維持）

## 制約
- 採点はデモ採点（発話長・音量ベース、音声認識なし）。本採点（Azure）は PC版 `sla-adhd-system` 側
- 進捗はその端末の localStorage のみ
